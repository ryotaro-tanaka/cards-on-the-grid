# 進捗レポート

## ロードマップ（現ゴール）

0. PWAで実装する。
1. クリーチャーは `game_rules.md` 記載の基本種＋スキル持ちを段階対応
2. カード実装フェーズ（仕様v0.4準拠）を完了する
3. 2人のプレイヤーが部屋に入室できる
4. ゲームを開始できる
5. 先行後攻はランダムに決まる
6. ターンプレイヤーはルール通りに移動/カード使用できる
7. ターンエンドできる
8. 相手がターンエンドしたら自分のターンが始まる
9. 勝利条件を満たすとゲーム終了する（ゲームルール通り）
10. backend/frontend/core のカード同期を安定運用する
